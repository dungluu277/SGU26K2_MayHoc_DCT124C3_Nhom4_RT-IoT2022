
## Lưu hình kết quả EDA

Chạy các cell trong `EDA.ipynb` như bình thường. Mỗi hình được tạo sẽ vừa hiển thị trong notebook, vừa tự động lưu thành file PNG trong thư mục `ket_qua_hinh` cạnh notebook.

Module `save_plots.py` quản lý việc lưu hình và tạo tên file riêng để không ghi đè các hình đã lưu trước đó.
